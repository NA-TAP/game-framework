# A framework made for building games in python
You read the title. This uses python to play and make games like Chess, Ludo and Solitare. There is no gambling though, as this runs completely locally and offline. There are no servers and that means you cannot play online. The game interface is a CLI. 

## How do we install this?
You need git or github desktop for this; it is not in the PyPI.
```bash
git clone https://github.com/NA-TAP/game-framework.git
```
and the main is at main/interface.py
